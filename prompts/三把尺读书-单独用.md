# 三把尺读书 · 单独用的启动 prompt

不开圆桌、想在任意一个 AI 对话（Claude、ChatGPT、Gemini）里用贝叶斯、奥卡姆剃刀、万有理论重新梳理一本书时，把下面整段贴进去，再把最后的模板填上。圆桌里的「三把尺读书」按的是同一套尺子。

---

请用三把尺重新梳理一本书。这三把尺是我看世界的坐标系：

- **贝叶斯**：数据只按「谁把它预测得更准」重新分配信任。一个主张该让人更新多少，取决于证据的似然比：如果这个主张是错的，这些证据还会不会照样出现？故事、幸存者案例、事后解释，似然比接近 1，不算证据。
- **奥卡姆剃刀（最小描述长度）**：好理论 = 好压缩，用最短的描述解释最多的现象。这本书真正独立的核心观点有几个？哪些只是换个说法重复？有没有更简单的解释（回归均值、幸存者偏差、选择效应、激励、运气）能解释同样的证据？
- **万有理论**：把它并进更大的统一。它的观点能不能归到一个更一般的原理下，是哪个原理的特例？它把哪些原来分开的现象统一了？统一之后多出什么新预测？它在哪里和其他成熟理论冲突，边界在哪？

请按这个顺序做，每一步都写出来：

1. **列观点**：把书的观点列成清单，编号 C1、C2……，8–20 条。每条写成一句可以被证伪的主张（「X 导致 Y」「做 A 比 B 更能……」），不要写成口号；括号标书里主要靠什么支撑：数据 / 实验 / 案例 / 个人经历 / 推理 / 引用权威。以我贴的内容为准，你凭对这本书的了解补的标「据我所知」。
2. **贝叶斯尺**：挑最要紧的 3–6 条，每条写：主要证据、似然比（强 / 中 / 接近 1）、读者该从几成更新到几成。能查的话，写这条主张后来有没有被重复验证或反驳。
3. **奥卡姆尺**：这本书的秩是几（几个独立的核心观点，各覆盖哪些 C）；哪些 C 是冗余；哪条有更简单的解释（写出来）。
4. **万有理论尺**：它是哪个更一般原理的特例；统一了什么；统一后的新预测；边界和冲突。
5. **一句话**：这本书最短的描述，一句话，能推出它大部分观点。
6. **读后该做什么不同**：1–3 件具体的事，或可以验证的预测（带检验时间）。
7. **自我攻击**：你在哪一把尺上最可能判断错，为什么。

拿不准的事实标「未查证」。不要替我下结论，也不要复述全书。
