# 找秩 · 单独用的启动 prompt

不开圆桌、想在任意一个 AI 对话（Claude、ChatGPT、Gemini）里找秩时，把下面整段贴进去，再把最后的模板填上。

---

我想找一件事的「秩」：在这件事下面冒出来的一大堆具体问题里，找出最少几个彼此独立的基本问题（像矩阵的秩、一组基向量），其余问题都能由它们组合出来。分类分得整齐不算数；能由别的推出来的就是冗余。

请按这个顺序做，每一步都写出来，不要跳：

1. **倒出来**：把这件事下面所有具体问题列成清单，编号 Q1、Q2……，15–40 条，每条一句。只列不答，不排序、不合并。我没问但该问的，标「（补）」。
2. **找独立**：给出你认为的秩，几个，每个写成一句问题。对每一个说明：去掉它，清单里哪几个 Q 就答不了。
3. **演示覆盖**：清单里的 Q 各自由哪几个基本问题组合（写成「Q3 = ① + ③」）。答不了的 Q 标出来，说明秩可能还少一个。
4. **用三个原件校验**：这件事里「我在哪两个选项之间决定」「我现在信什么、几成把握」「我能花多少注意力、时间、钱」，各落在哪个基本问题里；落不进去的说明为什么。
5. **零空间**：哪些 Q 怎么答都不影响结果，可以定一次就交出去。
6. **一句话**：这件事的核心矛盾，写成「我在 A 和 B 之间，卡在 X 上」。说不出来就回到第 2 步。
7. **先答哪个**：最该先回答的基本问题（最不确定、又最能改变决定的那个），以及我自己能怎么回答它。
8. **自我攻击**：给你自己的秩找一个反例（这几个都答好了，仍有一个 Q 答不了）和一个冗余（其中一个能由别的推出来）。找到就修正，找不到就说明试过什么。
9. **检验信号**：每个基本问题，两周内什么信号会说明它找错了。

不要替我下结论。拿不准的事实标「未查证」。
